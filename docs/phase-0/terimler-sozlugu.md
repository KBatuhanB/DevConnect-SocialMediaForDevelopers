# Terimler Sozlugu

## Temel Terimler
- MVP: Ilk surumde mutlaka calismasi gereken en kucuk urun kapsami.
- RLS: Satir bazli veri yetkilendirme mantigi.
- ADR: Alinan mimari veya surec kararinin yazili kaydi.
- DoD: Bir isin bitmis sayilmasi icin gereken kosullar.
- Feed: Takip edilen kullanicilarin icerik akisi.
- DM: Iki kullanici arasindaki birebir mesajlasma.
- Config: Degisebilir degerlerin tek yerde toplandigi dosya veya modul.
- Smoke test: Sistemin temel calisabilirligini hizlica kontrol eden test seti.
- Rollback: Basarisiz dagitim sonrasi guvenli geri donus adimi.
- Cursor pagination: Kayitlari sabit sayfa numarasi yerine isaretci ile getiren sayfalama yaklasimi.
- Idempotent: Ayni islem tekrarlandiginda sistem durumunu bozmayacak davranis.

## Projeye Ozel Kullanimi Olan Terimler
- Basit kod: Ihtiyaci karsilayan ama gereksiz soyutlama icermeyen kod.
- Yorum standardi: Kisa, Turkce ve karar noktalarini anlatan yorum bicimi.
- Modul config dosyasi: Ilgili feature'in tum oynanabilir degerlerini toplayan yerel ayar dosyasi.
