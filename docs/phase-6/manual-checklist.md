# Faz 6 Manuel Kontrol Listesi

## Zorunlu mu?
Hayir. Kod ve build dogrulamasi alindi. Bu adimlar sadece ek kontrol icindir.

## Adimlar
1. Root klasorde `npm run dev` calistir.
2. `/auth` ekranini ac.
3. Form alanlarinda hatali veri gir ve istemci tarafli hata mesajlarini kontrol et.
4. Gecerli kullanici ile giris yap.
5. `/dashboard` shell'ine yonlendigini kontrol et.
6. Dashboard icinde profil ozeti, kod onizleme ve medya yukleme kabugunun gorundugunu kontrol et.
7. `UI notlari` veya `Yardim` butonundan dialog acilip kapanabiliyor mu bak.
8. Cikis yap ve `/dashboard` adresine tekrar gitmeye calis.
9. Auth sayfasina geri donduruldugunu kontrol et.

## Beklenen Sonuc
- Formlar ortak UI stili ile calisir.
- Toast geri bildirimi gelir.
- Loading, bos durum ve hata desenleri hazirdir.
- Korumali shell mobil ve masaustu duzende kirilmaz.
